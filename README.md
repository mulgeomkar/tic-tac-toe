## 🕹 Tic-Tac-Toe Game  
A simple Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

### 🔗 Live Demo  
You can run this project by opening `index.html` in a browser.

### 📂 Project Structure  
- **index.html** → Main game UI  
- **script.js** → Game logic and event handling  

### 🚀 How to Run  
1. Clone this repository:  
   ```sh
   git clone https://github.com/mulgeomkar/tic-tac-toe.git
   ```
2. Open `index.html` in a web browser.  
3. Click on the grid to play the game.

###  Game Features  
✅ Two-player mode (X vs O)  
✅ Detects winner or draw  
✅ Simple and clean UI
